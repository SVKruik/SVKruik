# Hi there, I'm Stefan

I am a 20-year-old Dutch fourth-year Software Engineer major at the Amsterdam University of Applied Sciences specializing in Web and DevOps engineering.

I love working with both software and hardware, and I learn new techniques, languages and tools daily.

My larger and more advanced projects are available over at my GitHub organization instead of my personal account. You can find them [here](https://github.com/SVKruik-Organization), under [Active Projects](https://github.com/SVKruik#active-projects) below or pinned on my GitHub profile.

### Active Projects

Besides academic work over on GitLab, I also work on side projects to enlarge my portfolio and learn new stuff freely:

- [SK Platform](https://github.com/SVKruik-Organization/SK-Platform)
- [SK Overway](https://github.com/SVKruik-Organization/SK-Overway): single sign-on across all web-facing SK Platform applications.
- [Uplink](https://github.com/SVKruik-Organization/Uplink): A comprehensive RabbitMQ communication network that makes SK Platform a hive mind.
- [SK Administrator](https://github.com/SVKruik-Organization/SK-Administrator): the Houston control panel of SK Platform.

To support and streamline development I of all my Node projects also made a couple of [NPM packages](https://www.npmjs.com/settings/svkruik/packages).
